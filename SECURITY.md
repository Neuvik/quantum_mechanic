# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Send a concise report to security@neuvik.com with the affected version,
reproduction steps, impact, and any suggested mitigation. Do not include
customer data, credentials, access tokens, or other sensitive assessment
material.

We will acknowledge reports and coordinate remediation and disclosure with the
reporter when contact information is available.

## Supported Versions

Security fixes are applied to the current public release candidate and later
releases when practical.
